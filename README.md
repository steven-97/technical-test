# praxolvo25
Base code for technical test on candidates to perform their enterprise practices on Solvo.

## What to do?
The goal with this test is that you complete the code for a fully functional CRUD on the model, adding error handling on the existing routes and the ones that you will create and demonstrate your skills using git and the tools you can need to achieve this goal. 
Please fork this repo using git clone on your terminal, do at least 3 commits and create a pull request on a new branch named however you want.

# Technical Test – CRUD de Productos
This project is a technical test implementing a complete product CRUD application using a Node.js and Express backend and a React (Vite) frontend.

The goal is to demonstrate backend API development, frontend service consumption, basic error handling, and the Git workflow.

# Technologies Used

Backend

Node.js

Express

CORS

REST API

Frontend

React

Vite

JavaScript (ES6)

CSS (no frameworks)

Fetch API

# Features
Backend (REST API)

Create products

Retrieve all products

Retrieve product by ID

Update products

Delete products

Main endpoints:

GET /products
POST /products
PUT /products/:id
DELETE /products/:id

# Frontend
Product creation form

Product listing

Product update using a reusable form

Product deletion with confirmation

Clean and responsive UI

Direct communication with the backend API

# How to Run the Project

Backend

Navigate to the backend folder:

cd ap
npm install
npm start

The server will run at:

http://localhost:3000

# Frontend

Navigate to the frontend folder:

cd frontend
npm install
npm run dev

The application will be available at:

http://localhost:5173
